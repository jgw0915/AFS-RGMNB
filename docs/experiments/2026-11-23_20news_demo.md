# 2026/11/23：20 Newsgroups 原始文字與特徵擷取展示

## 交付目的

本次交給翁老師的是一個**可重現的 60 篇文章展示**，不是完整高維度資料集的正式分類效能實驗。使用 scikit-learn 的原始 20 Newsgroups 文字及標籤，通過本專案的 `DocumentPreprocessing` 和 `document_vectorizer`，輸出原始文字與整數字詞計數的對應表。

與上週學長保存的 18,828 筆、83,415 個實際觀察特徵的 20News 計數矩陣**不是同一個語料版本，也不是原先已儲存的詞頻向量之逆轉換**。不得宣稱重現了學長的字典、停用字表、歷史前處理或分類效能。

## 下載與本機執行

進入 `AFS-RGMNB` 專案根目錄（Windows PowerShell），確保 Python 3.10 環境可連接網路下載公開 20 Newsgroups：

```powershell
git switch refactor/full-thesis-framework
git pull --ff-only origin refactor/full-thesis-framework
python -m pip install -r requirements.txt
python -m pip install -e . --no-deps
python scripts/export_20news_60_demo.py --selection first60 --output outputs/2026-11-23/20news_demo
```

`first60` 表示 sklearn 使用 `subset=all`、`shuffle=True`、`random_state=42` 排序後的前 60 篇，**不是原始檔案中未打亂的第一至第六十篇**。若需在 20 個類別各展示三篇，可改用 `--selection three_per_class` 並指定不同輸出資料夾。

預設 `fetch_20newsgroups(remove=())`，第一份 CSV 保留取得的原始文章文字（包括郵件標頭）。在特徵萃取階段，本專案的 analyzer 會嘗試移除符合 RFC822 格式的標頭，再進行小寫、斷詞、明確的 sklearn English stopword 清單及 NLTK original Porter stemming。注意這些設定**不是已驗證的學長原始停用字清單**。如果想下載時就移除標頭、引言和簽名可使用 `--strip-metadata`，但第一份 CSV 便不能再稱為未清理原文。

## 預期的本機檔案（不提交到 GitHub）

| 本機檔案 | 內容 |
|---|---|
| `outputs/2026-11-23/20news_demo/20news_original_60.csv` | 60 篇來源文字、樣本 ID、來源索引、類別名稱、文字 SHA-256 |
| `outputs/2026-11-23/20news_demo/20news_extracted_word_counts_60.csv` | 稀疏長格式：同樣的樣本 ID、類別、此次字典的 feature_index、term、整數出現次數 |
| `outputs/2026-11-23/20news_demo/demo_manifest.json` | 版本、參數、類別分布、實測特徵數、非零值數量、方法與限制 |

第二份 CSV 只儲存**非零詞頻**，未列出的字詞視為 0；`feature_index` 是 60 篇本次擷取的零起始字典欄位索引，**不是**學長封存資料的 source feature ID。

CSV 第一份含原文，可能包含電子郵件地址或其他個資及著作權內容。原始下載快取、兩份 CSV、manifest 等完整逐筆資料一律留在受 `.gitignore` 保護的 `outputs/`，不要以任何方式推送到公開 GitHub、報告內全文轉貼或傳送給未經授權的人。若要向教授提供完整 CSV，先依資料使用條款檢查並使用學校允許的私人交付方式。

## 驗證方式

```powershell
python -m unittest discover -s tests -v
python tools/check_thesis_spec.py
git check-ignore -v outputs/2026-11-23/20news_demo/20news_original_60.csv
git status --short
```

檢查輸出：

1. `demo_manifest.json` 的 `sample_count=60`、`observed_vocabulary_features>0`、`nonzero_word_count_entries>0`；不得填入預估數。
2. `original_60.csv` 必須剛好有 60 列資料，樣本 ID 唯一，類別與來源索引一致；另一 CSV 所有樣本 ID 都能對應回原文。
3. 同一個字詞在同一篇文章的出現次數，應與專案的 analyzer / vectorizer 再次計算一致；允許同篇原文有多個相同字詞。
4. 保存 `scikit-learn`、`nltk`、Python 版本、完整命令及實際執行時間至本週交付紀錄。
5. 此 60 篇實作展示不能當作樣本數至少 500、特徵數至少 5,000 的正式高維度研究驗證；正式論文須在資料切分後僅從 `Dfit` 學習字典，不能以這次 60 篇共同擬合的字典評估測試表現。

## 老師可以如何閱讀這兩份資料

先在 `20news_original_60.csv` 找一筆 `sample_id` 的文字，再到 `20news_extracted_word_counts_60.csv` 使用同一 `sample_id` 篩選字詞與頻次。這能具體展示從文件文字到 MNB 所需非負整數詞頻的程式流程；它**不是**對原始學長詞頻資料再做降維／特徵選取，也不是 PSO 實驗結果。
